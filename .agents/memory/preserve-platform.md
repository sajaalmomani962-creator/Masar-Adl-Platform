name: Preserve the supplied platform
description: Why the supplied judicial platform is retained despite the initially selected React output.
---

Continue the supplied Python application and its server-rendered Arabic
interface, rather than rebuilding the product in React.

**Why:** The attached specification explicitly requires preserving the existing
application and its functionality. When the selected React output conflicted
with that requirement, the user authorized choosing the most appropriate
approach while maintaining the existing requirements. Preserving the application
avoids losing the established security and judicial workflow behavior.

**How to apply:** Treat the supplied implementation as the starting point for
future changes. A replacement frontend or different backend is a separate
architecture decision, not an implied consequence of the initial scaffold.
