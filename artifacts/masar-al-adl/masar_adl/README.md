# مسار العدل — نموذج أولي

التطبيق الأصلي محفوظ ومحدّث إلى **FastAPI** مع واجهة عربية RTL.
ليس نظامًا رسميًا ولا جاهزًا للإنتاج، ولا يتصل بأي نظام حكومي.

دليل المشروع الكامل، المتطلبات، التشغيل، متغيرات البيئة، SQL Server،
الأمان، الاختبارات والقيود المعروفة موجود في [README الرئيسي](../../../README.md).

من داخل هذا المجلد:

```bash
DATA_MODE=demo uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1
python -m pytest -q tests
```

شاشة الدخول العادية: `/login`.
للعرض بحسابات TEST فقط: `/login?demo=1`.
لا تُحفظ كلمات سر أو تجزئات في هذا الملف أو في SQL.
تُنشأ تجزئات Argon2id الجديدة تفاعليًا عبر `scripts/make_pin_hash.py`، وتبقى
تجزئات scrypt السابقة مدعومة. تُحفظ التجزئات الاختيارية في Secret
`DEMO_USERS_JSON` فقط.

ملفا `db/` مرجع فقط ولم يتغيرا ولا ينفّذهما التطبيق أو الاختبارات.
لم تُختبر قاعدة SQL Server حقيقية. تفاصيل خطوات العرض في
[DEMO_GUIDE.md](DEMO_GUIDE.md).

نتائج فحص جاهزية اتصال SQL Server وحدوده ومتطلبات الاتصال الخاص الآمن:
[SQLSERVER_VALIDATION.md](SQLSERVER_VALIDATION.md).

نتائج اختبارات الأدوار والواجهة في البيئة التجريبية وحدود التحقق:
[VERIFICATION.md](VERIFICATION.md).
